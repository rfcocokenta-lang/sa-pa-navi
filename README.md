# SA・PAナビ Prototype v0.11

今回の修正:
- 「館山駅」のような駅・施設名はNominatimの施設検索を優先し、住所検索APIによって別地点へ化ける問題を回避。
- 住所は国土地理院の住所検索を優先し、見つからない場合はNominatimへフォールバック。
- OSRMの通常代替ルートに加え、周辺の高速道路IC（motorway_junction）を候補にして「高速優先」ルートを明示的に生成。
- `exclude=motorway` を使った「一般道中心」ルートも明示的に生成。
- 高速優先・高速道路中心・一般道中心などを最大5候補から選択可能。
- 選択したルートに応じて地図、距離、ETA、SA/PA一覧を更新。

ドラぷら/NEXCOの考え方を参考に、複数ルートを比較して選択するUIにしています。ただしドラぷら/NEXCOの公式料金・渋滞・経路データそのものは使用していません。

公開OSM/Nominatim/OSRM/Overpass APIを利用する試作です。高頻度・商用利用では各サービスの利用条件に従い、専用APIと公式SA/PAデータへの切り替えを推奨します。
